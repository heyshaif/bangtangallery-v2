# Custom Music Directory for BANGTAN GALLERY

You can add any custom audio files (.mp3, .wav, .m4a, .aac, .ogg) in this folder directly using VS Code!

## How to use in VS Code:
1. Place your audio files here in `public/audio/` (e.g., `public/audio/dynamite.mp3`, `public/audio/spring_day.mp3`).
2. In the Admin Panel (Music tab) or in `src/data/btsData.ts`, set the **Audio URL** to:
   `/audio/dynamite.mp3`
   or
   `/audio/spring_day.mp3`
3. Click **Publish Live Instantly** in the Admin Panel or refresh the website.
4. Your custom audio will play smoothly through the music player!
